# sdoc-render

screendoc renderer: terminal frame rasterization, ffmpeg GIF/MP4 pipeline,
and a local web player.

The renderer turns a session's asciinema byte stream plus its chapter events
into derived artifacts: animated GIF/MP4 (via `ffmpeg`), an exported cast
copy, and a browser-based live player.
